# 概览

要更有效地使用 Rete，建议先理解几个核心概念。内容组织、学习流程与复习机制都建立在这些基础之上。

请按以下顺序阅读：

1. **概览**（本页）
2. [卡组](/guide/key-concepts/decks)
3. [词条](/guide/key-concepts/facts)
4. [卡片](/guide/key-concepts/cards)
5. [标签](/guide/key-concepts/tags)

## 各部分如何配合

**卡组** 是某一主题或目标的学习容器：名称、列结构、每日新卡节奏，以及其中的词条与卡片。

**字段** 是创建卡组时定义的列名（例如 `English` 与 `中文`），说明学习项中每一格的含义。字段标签只保存在卡组上；添加词条时按相同顺序填写 **条目**——条目 `0` 对应第一列，条目 `1` 对应第二列，以此类推。

**词条** 是底层学习内容：一条完整项（词对、概念、术语与释义等）。词条**不是**卡片。词条保存材料；系统据此生成你实际复习的卡片。

**卡片** 是你日常复习的对象。每张卡属于一条词条，有 **正面** 与 **背面**（哪些条目出现在哪一侧），并带有间隔重复调度（到期时间、是否隐藏等）。默认添加词条会生成 **一张** 卡（正面 = 第一条目，背面 = 其余）。同一词条也可有不同布局的 **同源卡片**——例如两种翻译方向——当系统为该内容提供多种模板时。

文本、图片、音频与视频保存在词条的 **条目** 中（不是独立的「卡片文件」）。卡组上的 **字段** 只是列名；详见[卡组](/guide/key-concepts/decks)与[词条](/guide/key-concepts/facts)。

## 一览

| 概念     | 作用                                                                            |
| -------- | ------------------------------------------------------------------------------- |
| **卡组** | 按主题组织内容；定义 **字段**（列）以及每天引入多少 **新卡**（内部为 `rate`）。 |
| **字段** | 卡组上的列名；词条按位置填写对应 **条目**。                                     |
| **词条** | 你创建与编辑的内容（各列条目，可选媒体）。                                      |
| **卡片** | 词条的一种可复习正/背面布局，带独立调度。                                       |
| **标签** | 可选，用于卡组与词条的组织与筛选学习。                                          |

## 关系

- 一个卡组包含许多 **词条** 与许多 **卡片**。
- 一条词条通常从 **一张** 卡开始；同一内容有多种布局时，可有 **两张及以上** 同源卡片。
- 每张卡精确指向该卡组中的 **一条** 词条。

## 典型流程

1. **获得卡组** — [从发现页导入共享卡组](/guide/get-started/import-an-existing-deck)，或[自己创建](/guide/get-started/create-your-deck)并设置字段与每日新卡节奏。
2. **添加或保留词条** — 在自有卡组中按列填写内容（及可选媒体）。系统为每条词条生成卡片。
3. **学习** — Rete 选出最紧急的待复习卡片；你看正面、显示答案，在 **困难** ↔ **简单** 之间评分，然后继续。也可按[标签](/guide/key-concepts/tags)筛选。
4. **维护** — 在自有卡组上编辑词条；在 **导入** 卡组上仍可打标签、调整新卡节奏、隐藏或删除单张卡，并以贡献形式提出修改建议。**隐藏** 卡片可将其移出队列而不删除词条。

## 源卡组与导入

你 **创建** 的卡组可自由编辑。**发布** 后，其他人可在 **发现** 中找到并 **导入** 一份个人学习副本，固定到该发布版本。导入卡组有自己的卡片与进度——不是指向作者工作副本的实时链接。详见[导入已有卡组](/guide/get-started/import-an-existing-deck)。
