# 词条

词条是 Rete 中用于生成卡片的最小内容记录。一条词条是一个完整的学习项——通常是词对、概念、术语与释义，或一小组成你想记住的相关信息。

词条**不是**卡片。词条保存底层材料；**卡片** 才是学习时看到的对象，各自有正/背面布局与调度。

词条**不**存储 **字段**。列名（**字段**）只存在于 **卡组**。每条词条保存 **条目**——各列位置上的实际文本与可选媒体。

## 条目

词条是一组 **条目**，与卡组字段列表顺序一一对应。若卡组字段为 `English` 与 `Japanese`：

- 条目 `0` → `English` → `hello`
- 条目 `1` → `Japanese` → `こんにちは`

每个条目可以包含：

- **文本** — 词语、释义、定义、例句、笔记
- **图片** — 上传后引用到该条目
- **音频** — 发音、朗读或与该条目相关的片段
- **视频** — 可选，用法与图片、音频相同
- **结构化数据** — 产品在需要时可为条目携带更丰富的载荷

你可以在同一条目上同时放文本与音频（例如 `hello` 加发音）。也可以让某一条目只有图片或声音——媒体仍属于 **词条**；卡组字段只是列标签。

编辑或复习时，Rete 可能用字段名作标签显示（如 `English: hello`），但词条只存储 **条目**，不存储列名。

卡组列越多，条目越多。完整的条目有助于系统生成有用的卡片，也让复习更易跟随。

## 生成卡片

词条是卡片的基础。**默认** 添加词条会生成 **一张** 卡：

- **正面** = 第一条目（索引 `0`）
- **背面** = 其余全部条目（`1`、`2`，…）

两个条目（`hello` / `こんにちは`）时即为：

正面：`hello`  
背面：`こんにちは`

三个及以上条目时，默认仍是「正面第一条目，背面其余全部」。

### 一条词条多张卡

同一内容模型也允许一条词条生成 **多张卡**（同源卡片）——例如英译日与日译英——以便多方向练习回忆。日常使用中，添加词条会生成 **默认的一张卡**；额外布局属于同一内容模型的进阶能力。

## 自有卡组与导入卡组

在你 **拥有** 的卡组上，可自由创建与编辑词条。

在 **导入** 卡组上，已发布快照定义共享源。你仍可用自己的进度学习、调整标签与新卡节奏，并处理卡片（含隐藏/删除）。内容修改建议可作为 **贡献** 发给作者，而不是静默改写已发布源。详见[导入已有卡组](/guide/get-started/import-an-existing-deck)与[菜单与操作](/guide/get-started/menus-and-actions)（**编辑词条**、**添加词条**、未发送贡献）。

## 小结

**卡组** 定义 **字段**（列名）。**词条** 按列顺序存储 **条目**（内容与媒体）。**卡片** 由词条生成，用于每日复习。卡组组织主题，词条保存材料，卡片承载学习体验——包括间隔、到期日与可选隐藏。
