# 标签

**标签** 是你贴在 **卡组** 与 **词条** 上的标记，用于组织与筛选材料。标签属于 **你的账户**，不属于某一个卡组——创建一次后，可在多个卡组与多条词条上使用。

标签是可选的。没有标签，卡组与词条也能正常使用；当你想分组内容（例如 `verb`、`JLPT N3` 或 `hard`），或只复习卡组中一部分卡片时，标签会很有用。

## 标签与卡组、词条的关系

| 位置     | 标签做什么                                                                |
| -------- | ------------------------------------------------------------------------- |
| **卡组** | 标记整个卡组（如 `Japanese`、`exam-prep`）。每个卡组最多 **100** 个标签。 |
| **词条** | 标记卡组内的单项（如 `noun`、`food`）。一条词条可以有多个标签。           |

**字段** 定义卡组上的列；**标签** 是用于筛选与组织的独立元数据。词条仍只存储 **条目**——标签关联在词条旁，不写进词条条目文本。

同一标签名可用于多个卡组与多条词条。删除标签会去掉所有关联。

在同一卡组内，词条级标签去重后最多 **200** 个。

## 创建与管理标签

创建或编辑卡组、词条时可添加标签（选择已有标签或按名称创建）；也可在应用中管理标签库（创建、重命名、删除）。

每个标签有 **名称** 与可选 **描述**。名称在规范化后须对你的账户唯一（去首尾空白、合并连续空格、不区分大小写比较）。允许 **Unicode** 字母与数字、空格、连字符（`-`）与撇号（`'`）。

**上限：**

- 每用户最多 **1000** 个标签
- 每个卡组最多 **100** 个标签
- 每个卡组内词条标签去重最多 **200** 个

## 为词条与卡组打标签

添加或编辑词条时可附带可选 **标签**——例如一行标为 `verb`，另一行标为 `food`。不同词条可以有不同标签，也可以没有。

创建卡组时或之后也可为卡组打标签——便于浏览你的库，不会改变单张卡的正/背面布局。

## 用标签学习

复习时，可只学习该卡组中带有某标签的词条对应的卡片。标签不改变卡片布局——只缩小 **哪些** 卡片进入学习。

## 导入卡组

在导入的卡组上，**标签属于你**，用于筛选与组织。标签与内容建议也可作为 **贡献** 发给作者；这与你的本地标签是分开的。共享词条正文仍跟随已发布快照，直到你同步更新。详见[导入已有卡组](/guide/get-started/import-an-existing-deck)。

## 小结

标签是账户级标记，用于 **卡组** 与 **词条** 的组织与筛选学习。它们补充卡组 **字段** 与词条 **条目**——后者才保存真正的学习材料。
