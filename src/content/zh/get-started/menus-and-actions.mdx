# 菜单与操作

本页说明应用中的主要 **菜单与按钮**。概念见[核心概念](/guide/key-concepts/overview)；首次上手见[快速开始](/guide/get-started/login-registration)。

**自有**卡组是你创建的；**导入**卡组来自「发现」。部分操作在两者上不同。

## 底部标签

| 标签     | 作用                                     |
| -------- | ---------------------------------------- |
| **卡组** | 你的库——打开卡组学习、创建卡组、管理标签 |
| **发现** | 公开目录——搜索、收藏、导入共享卡组       |
| **我的** | 账户设置（语言、主题、退出、邮箱验证）   |

## 卡组列表

在 **卡组** 页：

- **创建卡组**（悬浮按钮）— 打开创建面板（名称、字段、标签、每日新卡数）
- **标签**（顶栏）— 打开标签库（管理标签）
- 点击 **卡组卡片** — 进入该卡组的学习
- **发布卡组** / **发布更新**（自有卡组上的分享图标）— 发布或再次发布到「发现」
- **检查更新**（导入卡组上的刷新图标）— 查看并同步作者更新

## 卡组选项（学习时的 ⋯）

打开卡组后，使用卡组 **⋯** 菜单（**卡组选项**）：

| 操作           | 作用                                                  | 自有           | 导入                                  |
| -------------- | ----------------------------------------------------- | -------------- | ------------------------------------- |
| **字体**       | 调整本卡组正面/背面正文字号与注音                     | 是             | 是                                    |
| **添加词条**   | 打开 **添加词条**，新建学习项（条目 + 可选媒体/标签） | 直接保存到卡组 | 本地保存，并加入 **未发送贡献**       |
| **编辑卡组**   | 修改每日新卡数、标签；自有卡组还可改名称与字段        | 完整编辑       | 名称/字段锁定；仅可改每日新卡数与标签 |
| **发布卡组**   | 将卡组发布到「发现」                                  | 是             | 隐藏                                  |
| **贡献收件箱** | 处理导入者的修改建议与问题报告                        | 是（已发布源） | 隐藏                                  |
| **未发送贡献** | 查看可发给作者的本地修改                              | 隐藏           | 是                                    |
| **检查更新**   | 对比你的导入与最新发布                                | 隐藏           | 是                                    |
| **删除卡组**   | 永久删除卡组及其全部卡片与词条                        | 是             | 是                                    |

## 卡片选项（卡片上的 ⋯）

学习时打开卡片 **⋯** 菜单：

| 操作         | 作用                                    | 自有           | 导入                            |
| ------------ | --------------------------------------- | -------------- | ------------------------------- |
| **隐藏卡片** | 将该卡移出队列，不删除词条              | 是             | 是                              |
| **编辑词条** | 打开 **编辑词条**，修改条目、媒体与标签 | 直接保存到卡组 | 本地保存，并加入 **未发送贡献** |
| **报告问题** | 向作者标记问题（音频、内容或其他）      | 隐藏           | 立即发送                        |
| **删除卡片** | 只删除 **这一张卡**；词条及其他卡片保留 | 是             | 是                              |

### 编辑词条

**编辑词条** 打开当前卡片对应词条的完整编辑面板：

- 编辑各 **条目**（文本与媒体：图片、视频、音频）
- **添加标签** / 移除词条标签
- **保存词条** — 自有卡组直接更新源内容；导入卡组更新本地副本，并加入稍后可发送的待处理贡献

卡组菜单中的 **添加词条** 使用同类面板创建 **新** 行。

## 学习控制

复习时（另见[开始学习](/guide/get-started/start-studying)）：

- 标签芯片 / **按标签复习** — 缩小到期范围
- **显示答案** — 揭示背面
- **困难** ↔ **简单** 滑块 — 选择下次复习间隔
- **下一个** — 保存评分并加载下一张
- **再次复习** — 在 **全部完成！** 后重新开始

## 发布、同步与贡献

| 流程                        | 入口             | 用途                                                 |
| --------------------------- | ---------------- | ---------------------------------------------------- |
| **发布卡组** / **发布更新** | 卡组列表或卡组 ⋯ | 让卡组出现在「发现」（或推送新版本）                 |
| **检查更新** / **立即同步** | 导入卡组         | 拉取作者变更；可按词条接受或拒绝                     |
| **贡献收件箱**              | 自有已发布卡组 ⋯ | 接受、忽略或解决导入者的建议与报告                   |
| **未发送贡献**              | 导入卡组 ⋯       | 将暂存的词条修改、新增词条、标签变更发给作者——或忽略 |

详情见[导入已有卡组](/guide/get-started/import-an-existing-deck)。

## 标签

- **管理标签**（卡组页顶栏）— 创建、编辑、删除标签；浏览某标签下的词条
- 创建/编辑卡组或添加/编辑词条时的 **添加标签** — 为该卡组或词条选择或创建标签
- 学习筛选只用 **当前卡组** 内的词条标签

见[标签](/guide/key-concepts/tags)。

## 发现

在 **发现** 页：

- 搜索与筛选（**最新**、**收藏**）
- 爱心 — 收藏/取消收藏目录卡组
- 打开卡组 → **导入**，再 **去学习**

见[导入已有卡组](/guide/get-started/import-an-existing-deck)。

## 小结

用 **卡组 ⋯** 菜单添加/编辑卡组、发布、同步与贡献；用 **卡片 ⋯** 菜单 **编辑词条**、隐藏、删除与报告。自有卡组直接保存修改；导入卡组上的多数内容修改会作为贡献暂存，再发给作者。
