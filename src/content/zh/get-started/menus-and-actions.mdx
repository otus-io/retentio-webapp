# 菜单与操作

本页说明应用中的主要 **菜单与按钮**。概念见[核心概念](/guide/key-concepts/overview)；首次上手见[快速开始](/guide/get-started/login-registration)。

**自有**卡组是你创建的；**导入**卡组来自「发现」。部分操作在两者上不同。

## 底部标签

| 标签     | 作用                                         |
| -------- | -------------------------------------------- |
| **卡组** | 你的库——打开卡组学习、创建卡组、管理标签     |
| **发现** | 公开目录——搜索、收藏、导入共享卡组           |
| **我的** | 语言、主题、统计、标签、邮箱、退出、删除账号 |

在网站上，顶栏是 **我的卡组**、**共享卡组** 和 **统计**。**共享卡组** 与应用里的 **发现** 是同一目录。

**发现** 不登录也能用。**卡组** 和 **我的** 会要求登录。

## 卡组列表

在 **卡组** 页：

- **创建卡组**（悬浮按钮）— 打开创建面板（名称、简介、字段、标签、每日新卡数）
- **标签**（顶栏）— 打开标签库（管理标签）
- 点击 **卡组卡片** — 进入该卡组的学习
- **发布卡组**（卡组 ⋯）与 **更新已发布版本**（卡组 ⋯；有未发布变更时也可点分享图标）— 发布到「发现」
- **检查更新**（导入卡组上的刷新图标）— 查看并同步作者更新

## 卡组选项（学习时的 ⋯）

打开卡组后，使用卡组 **⋯** 菜单（**卡组选项**）：

| 操作           | 作用                                                    | 自有           | 导入                                                      |
| -------------- | ------------------------------------------------------- | -------------- | --------------------------------------------------------- |
| **字体**       | 调整本卡组正面/背面正文字号与注音                       | 是             | 是                                                        |
| **添加词条**   | 打开 **添加词条**，新建学习项（条目 + 可选媒体/标签）   | 直接保存到卡组 | 保存在你的副本上并发送贡献。发送失败则留在 **未发送贡献** |
| **编辑卡组**   | 修改每日新卡数与标签。自有卡组还可改名称、简介与字段    | 完整编辑       | 名称、简介与字段锁定；仅可改每日新卡数与标签              |
| **发布卡组**   | 发布到「发现」。再次发布时面板标题为 **更新已发布版本** | 是             | 隐藏                                                      |
| **贡献收件箱** | 处理导入者的修改建议与问题报告                          | 是（发布之后） | 隐藏                                                      |
| **未发送贡献** | 重试或忽略未能发出的贡献                                | 隐藏           | 是                                                        |
| **检查更新**   | 对比你的导入与最新发布                                  | 隐藏           | 是                                                        |
| **QA 模式**    | 按列检查词条并标记字段已核验                            | 是             | 是。离开时把核验结果发给作者                              |
| **删除卡组**   | 永久删除卡组及其全部卡片与词条                          | 是，直到发布   | 是                                                        |

## 卡片选项（卡片上的 ⋯）

学习时打开卡片 **⋯** 菜单：

| 操作         | 作用                                    | 自有           | 导入                                                      |
| ------------ | --------------------------------------- | -------------- | --------------------------------------------------------- |
| **隐藏卡片** | 将该卡移出队列，不删除词条              | 是             | 是                                                        |
| **编辑词条** | 打开 **编辑词条**，修改条目、媒体与标签 | 直接保存到卡组 | 保存在你的副本上并发送贡献。发送失败则留在 **未发送贡献** |
| **报告问题** | 向作者标记问题（音频、内容或其他）      | 隐藏           | 立即发送                                                  |
| **删除卡片** | 只删除 **这一张卡**；词条及其他卡片保留 | 是             | 是                                                        |

### 编辑词条

**编辑词条** 打开当前卡片对应词条的完整面板。**添加词条** 用同一面板新建一行。

- 编辑各 **条目**。每一行需要文字，或至少一个附件。
- 可附加 **图片**、**视频** 或 **音频**。长按附件即可移除。也可以从相册选择照片或视频，或用麦克风录音（再点一次停止；录音中长按则丢弃）。
- 选中文字后点 **注音**，在这些字上方加上读音。卡组菜单里的 **字体**（**字体与注音**）可为 **正面** 和 **背面** 分别设置 **正文字号** 与 **注音字号**。
- **添加标签** / 移除词条标签
- 在自有卡组上，**添加词条** 时可勾选 **我已检查此词条（标记为已核验）**
- **保存词条** — 自有卡组直接更新源内容；导入卡组更新你的副本，并把修改发给作者。发送失败时，可从 **未发送贡献** 重试

## 学习控制

复习时（另见[开始学习](/guide/get-started/start-studying)）：

- 标签芯片 / **按标签复习** — 缩小到期范围
- **显示答案** — 揭示背面
- **困难** ↔ **简单** 滑块 — 滑块上显示下次间隔（从秒到年）。**困难** 是较短的一端，**简单** 是较长的一端
- **下一个** — 保存评分并加载下一张
- **再次复习** — 在 **全部完成！** 后重新开始

## 发布、同步与贡献

| 流程                              | 入口             | 用途                                                 |
| --------------------------------- | ---------------- | ---------------------------------------------------- |
| **发布卡组** / **更新已发布版本** | 卡组列表或卡组 ⋯ | 让卡组出现在「发现」（或推送新版本）                 |
| **检查更新** / **立即同步**       | 导入卡组         | 拉取作者变更；可按词条接受或拒绝                     |
| **贡献收件箱**                    | 自有已发布卡组 ⋯ | 接受、忽略或解决导入者的建议与报告                   |
| **未发送贡献**                    | 导入卡组 ⋯       | 将暂存的词条修改、新增词条、标签变更发给作者——或忽略 |

如何发布并和朋友一起改卡组，见[创建卡组](/guide/get-started/create-your-deck)。导入与同步见[导入已有卡组](/guide/get-started/import-an-existing-deck)。

## 标签

- **管理标签**（卡组页顶栏）— 创建、编辑、删除标签；浏览某标签下的词条
- 创建/编辑卡组或添加/编辑词条时的 **添加标签** — 为该卡组或词条选择或创建标签
- 学习筛选只用 **当前卡组** 内的词条标签

见[标签](/guide/key-concepts/tags)。

## 发现

在 **发现** 页：

- 搜索与筛选（**最新**、**收藏**）
- 爱心 — 收藏/取消收藏目录卡组
- 打开卡组 → **导入**，再 **去学习**

见[导入已有卡组](/guide/get-started/import-an-existing-deck)。

## QA 模式

**QA 模式** 在卡组 **⋯** 菜单里。它逐条检查词条，避免错误一直留在卡组中。

1. **选择列**。只有选中的列会出现，并且会记住你在这个卡组上的选择。
2. 点击 **开始 QA**。
3. 勾选看起来正确的列。有问题时用铅笔 **编辑词条**。**跳过** 不核验并继续（这条会在之后的检查中再出现）。**上一条** 返回。**已核验** 签核已勾选的列并进入下一条。
4. 结束时显示：**这些栏目已核验完成，谢谢。**

自有卡组上，这些签核直接算数。导入卡组上，离开 QA 模式会把签核发给作者——只包括你核验过、且仍与作者版本一致的字段。作者在 **贡献收件箱** 里看到它们。全部核验完成的卡组，卡片上会显示 **已完成人工校验**。

## 我的

打开 **我的** 页：

- **更改语言** — English、中文或 日本語
- **更改主题** — **浅色**、**深色**、**护眼模式** 或 **跟随系统**
- **统计** — 查看 **7**、**30**、**90** 或 **365** 天的复习，可针对一个卡组或 **全部卡组**。日期按 UTC 划分
- **标签** — 与 **管理标签** 是同一套标签库
- **修改邮箱** — 用密码确认
- **退出登录** — 若还有学习记录没有上传，可选择 **同步后退出**、**保留并退出** 或 **丢弃并退出**
- **删除账号** — 永久删除账号、私有卡组和学习进度。用密码确认。已发布的卡组仍可供导入者使用，但不再显示你的名字

若邮箱尚未验证，**我的** 页还会显示提醒和 **重新发送验证邮件**。发布和发送贡献都需要完成验证。见[登录与注册](/guide/get-started/login-registration#邮箱验证)。

## 小结

用 **卡组 ⋯** 菜单添加/编辑卡组、发布、同步、QA 与贡献；用 **卡片 ⋯** 菜单 **编辑词条**、隐藏、删除与报告。自有卡组直接保存修改。在导入卡组上，保存词条会更新你的副本，并把修改发给作者。
