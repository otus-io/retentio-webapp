# 创建卡组

[登录](/guide/get-started/login-registration) 后，你可以建立自己的学习材料：创建 **卡组**、添加 **词条**，由系统生成用于复习的 **卡片**。卡组、词条与卡片的关系见[核心概念](/guide/key-concepts/overview)。

若想先用现成材料，可先[从「发现」导入共享卡组](/guide/get-started/import-an-existing-deck)。

## 创建卡组

打开 **卡组** 页，点击 **创建卡组** 按钮（悬浮按钮）打开创建面板。

### 每日新卡数

选择每天学习多少张 **新卡**。该设置决定每日进入复习队列的新卡数量——请按可投入的学习时间选择：数值越大，新内容进入越快；越小，节奏越平缓。

### 卡组名称

卡组名称用于在库中标识该卡组，在创建面板中填写即可。

### 简介

**简介** 必填。别人在 **发现** 中打开卡组时会看到它，最多 **500** 个字符。导入卡组的简介跟随作者，不能修改。

### 标签

创建时可选择添加 **标签**，方便之后筛选学习。详见[标签](/guide/key-concepts/tags)。

### 字段（列）

定义 **字段**（列名）——例如 `English`、`Japanese`、`Example Sentence` 或 `Note`。字段名保存在卡组上，用于编辑与复习时的列标签。

默认提供 **2** 个字段；可调整顺序，并用 **添加字段** 增加更多列。词条按相同顺序填写 **条目**。详见[卡组](/guide/key-concepts/decks)。

点击 **保存**。新卡组会出现在库中——进入后即可添加内容。

## 添加词条

在卡组内添加 **词条**：一条完整的学习项（词对、术语与释义等）。每条词条按列顺序保存 **条目**，本身不存储字段名。

示例：字段为 `English` 与 `Japanese` 时——一行即一条词条：

| English | Japanese   |
| ------- | ---------- |
| hello   | こんにちは |

列越多，条目越多（例句、图片、音频、注释等）。详见[词条](/guide/key-concepts/facts)。

## 生成卡片

添加词条后，系统会根据 **条目** 生成 **卡片**。

**默认** 每条词条生成一张卡：正面 = 第一条目，背面 = 其余条目。

正面：`hello`  
背面：`こんにちは`

一条词条也可生成多张 **同源卡片**（如英译日与日译英）。详见[卡片](/guide/key-concepts/cards)。

## 发布你的卡组

发布分享的是卡组的 **快照**，不是指向你工作副本的实时链接。发布后你仍可继续编辑。朋友只有在你再次发布后才能看到这些修改。

```
你的工作卡组  →  发布卡组  →  公开快照 v1
                                  ↓
                     朋友导入  →  他们的学习副本（固定在 v1）
```

发布，以及把修正发给别人，需要[已验证的邮箱](/guide/get-started/login-registration#邮箱验证)。

### 首次发布

卡组准备好给其他人使用时：

1. 打开卡组 **⋯** 菜单，或打开卡组详情页。
2. 选择 **发布卡组**。

卡组会出现在 **发现** 中，标记为 **公开**，版本为 **v1**。

首次发布之后一直有效：

- 卡组保持公开。不能再改回私有。
- 已发布的卡组不能删除。

每位导入的朋友都有自己的卡片、到期日和进度。他们看不到你的复习记录，也不能直接改你的工作副本。

### 发布更新

发布之后的修改会留在工作副本上，直到你再次发布。

1. 照常修改词条、媒体、标签或卡组本身。
2. 在卡组 **⋯** 菜单中打开 **更新已发布版本**。有未发布的变更时，卡组卡片上的分享图标会打开同一面板。
3. 查看预览：新增、修改或删除的词条，以及媒体、标签和模板变更。
4. 发布。这会生成下一份快照（`v2`、`v3`，依此类推）。

若与上一版本没有差别，就没有新内容可发布。导入副本会停在对方已有的版本，直到他们自己选择更新。

## 和朋友一起改卡组

朋友并不共用一份实时卡组。他们导入你发布的快照，在自己的副本上学习，并在修正或新词条应当进入源卡组时发送 **贡献**。你决定保留哪些，再发布更新，其他人才能收到。

### 修正或新增

在导入的卡组上：

- **编辑词条**（卡片 **⋯**）— 改正条目、例句或媒体。保存会更新他们自己的副本，并把修正发给你。
- **添加词条**（卡组 **⋯**）— 以同样方式提议一条新词条。
- **报告问题**（卡片 **⋯**）— 标记音频、内容或其他问题。会立即发送，且不改动词条。

在导入卡组上改 **标签** 也会同样发送：卡组标签从 **编辑卡组** 发出，词条标签随 **编辑词条** 一起发出。

若发送未能完成，修改会留在 **未发送贡献**（卡组 **⋯**）里。该面板有 **待发送** 和 **已发送**，可加一句可选说明，再 **发送所选**、**忽略所选** 或 **清空全部**。

评分、隐藏的卡片和到期日留在他们自己的副本上，不会被发送。

### 处理朋友发来的内容

在你已发布的卡组上，从卡组 **⋯** 菜单打开 **贡献收件箱**。有待处理项时，卡组卡片上的收件箱图标会打开同一列表。每条会显示变更：编辑是修改前与修改后，其余是提议的词条、字段或标签。

| 操作           | 作用                                   |
| -------------- | -------------------------------------- |
| **接受**       | 把建议写入你的工作副本                 |
| **忽略**       | 丢弃                                   |
| **标为已解决** | 关闭且不应用。适合已经处理过的问题报告 |
| **全部接受**   | 接受所有待处理建议。问题报告会被跳过   |

接受不会更新「发现」。要让导入者收到这些变更，需再用 **更新已发布版本** 发布一次。

### 拉取新版本

导入副本会停在当前版本，直到对方更新。另见[导入已有卡组](/guide/get-started/import-an-existing-deck)。

1. 从卡组 **⋯** 菜单打开 **检查更新**，或点击卡组卡片上的刷新图标。
2. 查看新增、修改和删除的词条。
3. 对他们本地也改过的词条，选择 **接受**（采用已发布的写法）或 **拒绝**（保留自己的）。
4. 点击 **立即同步**。

同步后，被删除的词条会消失，新词条会生成新卡片。词条本身没变的卡片会保留复习记录。

## 下一步

卡组中有了词条与卡片后，即可[开始学习](/guide/get-started/start-studying)：看正面回忆，显示答案，选择难易，再点 **下一个**。
