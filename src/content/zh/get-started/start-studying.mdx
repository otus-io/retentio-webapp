# 开始学习

卡组中已有词条与卡片后——无论是[导入](/guide/get-started/import-an-existing-deck)还是[自建](/guide/get-started/create-your-deck)——从 **卡组** 页打开要学的卡组即可复习。Rete 会选出最紧急的待复习卡片——也可按[标签](/guide/key-concepts/tags)筛选——并引导你完成 **回忆**、**显示答案**、**选择难易**。

## 看正面并回忆

先显示卡片 **正面**：来自词条的一条或多条 **条目**（界面常带字段标签，如 `English:`）。

示例：

`English: hello`

请先自行回忆答案，再翻开背面——例如 `こんにちは`。主动回忆比「看着眼熟」更有效。

正面也可包含图片、音频或视频，取决于条目与卡片布局。

当前复习进度会显示为 **今日待复习**，便于查看当天目标完成情况。

## 显示答案

准备好后，点击卡片或底部按钮 **显示答案**。

**背面** 出现，用于核对回忆是否正确：

正面：`hello`  
背面：`こんにちは`

记得好说明已有基础；记得不牢则会在后续复习中更快再次出现。

## 困难或简单

答案显示后，使用底部的 **难度滑块**。**困难** 在左，**简单** 在右——根据真实回忆感受选择。

- 几乎想不起来或很吃力 → 偏 **困难**
- 快速、准确想起 → 偏 **简单**

请如实选择，随意打分会影响调度。

点击 **下一个** 保存评分并加载下一张卡片。算法据此安排下次出现时间：越难的卡越早再出现，越简单的卡间隔可拉长。

## 标签筛选

若卡组有标签，可用筛选标签（**全部** 或某一标签）缩小复习范围。需要完整队列时再清除筛选。

## 学习循环

每张卡重复同一流程：

1. 看 **正面** 并回忆
2. **显示答案** 并核对
3. 选择 **困难** 或 **简单**，再点 **下一个**

完成当日所有到期卡片后，可能看到 **全部完成！**——保持稳定的每日习惯，比临时猛刷更有效。

## 小结

**开始学习** 是间隔重复发生的地方：正面 → 显示答案 → 难易 → **下一个**。内容可通过[发现页导入](/guide/get-started/import-an-existing-deck)或[创建卡组](/guide/get-started/create-your-deck)准备；本页说明日常复习流程。
