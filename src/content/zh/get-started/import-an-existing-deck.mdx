# 导入已有卡组

最快的开始方式是从 **发现** 导入共享卡组，再像普通卡组一样复习。若想完全自己掌控内容，也可[创建卡组](/guide/get-started/create-your-deck)。

## 在「发现」中找卡组

1. 打开底部导航的 **发现** 页。
2. **搜索** 卡组、作者或标签，或按 **最新** 浏览。
3. 点击爱心收藏卡组（保存在本设备）。
4. 点击卡组卡片进入详情——名称、作者、词条数、字段、标签与简介。

## 导入并去学习

在详情页点击 **导入**。Rete 会在你的账户中新建一个 **学习卡组**——你自己的卡片、到期日与进度，并固定到所导入的已发布版本。它不是指向作者私有工作副本的实时链接。

导入完成后，点击 **去学习**。会跳到 **卡组** 页并刷新列表；打开该卡组即可开始复习。

导入需要先登录。未登录时，点击导入会先跳转到[登录与注册](/guide/get-started/login-registration)。

## 共享如何运作

**作者（源卡组）** — 正常建卡组后执行 **发布卡组**。发布会生成带版本号的 **公开** 快照（`v1`、`v2` …），并出现在「发现」中。作者可继续改工作副本；导入者只有在作者再次发布后才能看到新变更。

**你（导入卡组）** — 从该快照导入到自己的库中。

```
作者工作卡组  →  发布  →  公开快照 v3
                              ↓
                     你导入  →  你的学习副本（固定在 v3）
```

## 导入卡组上你可以改什么

- **每日新卡数** — 可在自己的副本上调整
- **标签** — 可为卡组与词条打标签以便筛选
- **名称与字段** — 跟随已发布快照（导入副本上不可随意改名或改字段结构）
- **建议修改** — 可对词条提出修改，以贡献形式发给作者，而不是静默改写共享源

条目与标签的细节见[词条](/guide/key-concepts/facts)与[标签](/guide/key-concepts/tags)。

## 作者更新卡组时

作者可在修正或新增词条后 **重新发布**。你的导入会停留在所选版本，直到你主动更新。

1. **检查更新** — 对比你固定的版本与最新发布
2. **立即同步**（可选） — 拉取更新快照；不会自动同步

同步后，导入内容反映新快照。已删除词条对应的卡片会消失；新词条会生成新卡片。底层词条未变时，已有卡片的复习历史会保留。

## 发布你自己的卡组

若你建好了卡组并希望别人在「发现」中找到：

1. 完成工作卡组（字段、词条、卡片）
2. 使用 **发布卡组**（卡组列表或卡组菜单）
3. 首次公开发布后，其他人即可在「发现」中导入

有实质变更时，用 **发布更新** 再次发布。

## 下一步

导入后，与自建卡组一样[开始学习](/guide/get-started/start-studying)。
