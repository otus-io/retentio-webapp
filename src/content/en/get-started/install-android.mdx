# Install on Android

Use the **same Google account** for each step.

1. **Join the group** — open [Google Groups](https://groups.google.com/g/rete-learning) and click **Join group**. Group members can become testers.
2. **Become a tester** — open [Google Play](https://play.google.com/apps/testing/srs.app.retentio) and tap **Become a tester**, then follow the link to the app and tap **Install**.

## No Google Play access?

If your device has no Google Play Store, install the APK directly:

[Download the latest Rete APK](https://github.com/otus-io/retentio-frontend/releases/latest/download/retentio.apk).
