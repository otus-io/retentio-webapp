# Create Your Deck

After you [log in](/guide/get-started/login-registration), you can build your own study material: create a **deck**, add **facts**, and let Rete generate **cards** for review. For how decks, facts, and cards relate, see [Key concepts](/guide/key-concepts/overview).

If you want ready-made material first, [import a shared deck from Discover](/guide/get-started/import-an-existing-deck) instead.

## Create a deck

Open the **Decks** tab and tap the **Create Deck** button (floating action button) to open the create sheet.

### Rate (new cards per day)

Choose how many **new cards** to introduce per day (`cards per day`). That sets how much fresh material enters your review queue each day — pick a value that matches the time you can study. Higher values introduce new material faster; lower values keep a steadier pace.

### Deck name

The deck name identifies the deck in your library. Enter it in the create sheet.

### Tags

Optionally add **tags** when you create the deck so you can filter study later. See [Tags](/guide/key-concepts/tags).

### Fields (columns)

Define **fields** (column names) — for example `English`, `Japanese`, `Example Sentence`, or `Note`. Field names live on the deck; they label each column when you edit and study.

By default you get **2** fields; you can reorder columns and **Add field** for more. Facts fill **entries** in the same order as those columns. See [Decks](/guide/key-concepts/decks).

Tap **Save**. The new deck appears in your library — open it to add content.

## Add facts

Inside the deck, add **facts**: one complete item to remember (word pair, term + definition, and so on). Each fact stores **entries** in column order — not field names on the fact itself.

Example on a deck with fields `English` and `Japanese` — one row is one fact:

| English | Japanese   |
| ------- | ---------- |
| hello   | こんにちは |

With more columns you add more entries (example sentences, images, audio, notes). Details are in [Facts](/guide/key-concepts/facts).

## Generate cards

When you add a fact, the system creates **cards** from its entries.

**By default**, one fact yields one card: front = first entry, back = the rest.

Front: `hello`  
Back: `こんにちは`

One fact can also produce **sibling** cards — for example English→Japanese and Japanese→English. See [Cards](/guide/key-concepts/cards).

## Publish to Discover

When the deck is ready for others, use **Publish Deck**. Published decks appear in **Discover** so other learners can import them. Republish with **Publish updates** when you make real changes. See [Import an existing deck](/guide/get-started/import-an-existing-deck) for how sharing and sync work for importers.

## What’s next

When your deck has facts and cards, [start studying](/guide/get-started/start-studying): recall the front, show the answer, rate difficulty, then tap **Next**.
