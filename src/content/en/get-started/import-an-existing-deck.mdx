# Import an existing deck

The fastest way to start studying is to import a shared deck from **Discover**, then review it like any other deck in your library. You can also [create your own deck](/guide/get-started/create-your-deck) when you want full control.

## Find a deck in Discover

1. Open the **Discover** tab (bottom navigation).
2. **Search** decks, authors, or tags, or browse with **Latest**.
3. Optionally save decks with the heart as **Favorites** (saved on this device).
4. Tap a deck card to open its detail page — name, author, fact count, fields, tags, and description.

## Import and go study

On the detail page, tap **Import**. Rete adds a **new deck to your account** — your own cards, due dates, and progress, pinned to the published version you imported. It is not a live link to the author’s private working copy.

When import finishes, tap **Go study**. That takes you to the **Decks** tab with your library refreshed; open the imported deck to start reviewing.

You need to be signed in to import. If you are not logged in, Import sends you to [login / registration](/guide/get-started/login-registration) first.

## How sharing works

**Author (source deck)** — Builds a deck as usual, then **Publish Deck**. Publishing creates a versioned **public** snapshot (`v1`, `v2`, …) that appears in Discover. The author can keep editing their working copy; importers only see new changes after a later publish.

**You (import deck)** — Import from that snapshot into your library.

```
Author working deck  →  publish  →  public snapshot v3
                                        ↓
                              you import  →  your study copy (pinned to v3)
```

## What you can change on an import

- **Rate** (new cards per day) — adjustable on your copy
- **Tags** — you can tag the deck and facts for filtering
- **Name and fields** — follow the published snapshot (not freely renamed/restructured on the import)
- **Suggested edits** — you can propose fact changes that go to the author as contributions, rather than silently rewriting the shared source

See [Facts](/guide/key-concepts/facts) and [Tags](/guide/key-concepts/tags) for how entries and tags behave.

## When the author updates the deck

Authors can **republish** after fixes or new facts. Your import stays on the version you chose until you update.

1. **Check updates** — compare your pinned version to the latest publish
2. **Sync now** (optional) — pull a newer snapshot; there is no automatic sync

After sync, your import reflects the new snapshot. Cards for removed facts go away; new facts get new cards. Review history for cards that still exist is preserved when the underlying fact is unchanged.

## Publishing your own deck

If you built a deck and want others to find it in Discover:

1. Finish the working deck (fields, facts, cards)
2. Use **Publish Deck** (from the deck list or the deck menu)
3. After the first public publish, others can import it from Discover

Republish with **Publish updates** when the working copy has real changes.

## What’s next

After import, [start studying](/guide/get-started/start-studying) the same way as with a deck you created yourself.
